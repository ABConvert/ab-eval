# Code of Conduct

This project follows the [Contributor Covenant, version 2.1][cc].

In short: be respectful, assume good faith, and keep discussion technical. Harassment,
personal attacks and demeaning comments are not acceptable in issues, pull requests, or any
other project space.

Report unacceptable behaviour to the maintainers through a private GitHub security advisory or
by email to the address on the organisation profile. Reports are handled confidentially, and
the maintainers will respond within a week.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
