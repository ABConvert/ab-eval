All four or none: cached reads and writes are billed at their own rates, and a run that knew only some of them would report a cost that is quietly wrong. Leave every one empty and a run reports tokens without a price.
Run limits for this model{{ ' — ' ~ (caps | length) ~ ' set' if caps }}

What one case gets before the harness stops it. Every box empty and the harness defaults apply, which is what every model got before this block existed. A cap belongs to the model as much as to the task: local weights at seventeen tokens a second need a longer clock than a hosted API to reach the same answer, and in bench-v2 one shared thirty minute limit stopped the slowest model twenty-seven times and the fastest never — which lowered its score for being slow rather than for being wrong. A --max-turns or --wall-clock passed on the command line beats what is set here, for that run only, and whatever ends up in force is written into the run's summary.json.
